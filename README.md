# Strategy Tools — student site

Public site for the strategic management student tools (GitHub Pages).

Live at: https://king-tuerto.github.io/strategy-tools/

This repo holds finished pages only. Do not edit the tool files here.

- The tools are built elsewhere: the `660` folder next to this one, under
  `Final First Draft Docs` > `HTML Tools`. The Toolkit's source is the private
  `strategy-toolkit` repo.
- `index.html` (the landing page) is the only page written here.

## To update the site

1. Run `publish.ps1` in this folder. It copies the current tools in.
2. Commit and push to the `gh-pages` branch. The live site updates in a minute or two.

The web address never changes, so instructors post the link once.
